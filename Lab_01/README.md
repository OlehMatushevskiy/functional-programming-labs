# Лабораторна №1. Облік електроенергії

Варіант 7. Програма отримує попередній та поточний показники лічильника і тарифну групу. Споживання дорівнює різниці показників. Вартість до пільги дорівнює споживанню, помноженому на тариф групи. Потім до цієї вартості застосовується пільга. Показники мають бути скінченними та не спадати. Сума кожної квитанції округлюється до копійок, а загальна сума складається з уже округлених квитанцій.

- `core.py` створює нові записи квитанцій без зміни вхідних даних. Фабрика `make_processor` приймає дві функції через `typing.Callable`: вибір тарифу за групою та застосування пільги до суми.
- `compose` поєднує перетворення відсотка пільги на частку з розрахунком частки до сплати. `make_multiplier` повертає функцію множення на задане число. Список квитанцій створюється через списковий вираз.
- `app.py` містить `main()`, яка задає демонстраційні показники і правила та друкує квитанції. Тарифи й відсотки обрані для прикладу.
- `main.py` запускає функцію `main()` з `app.py`.
- `tests/test_core.py` перевіряє повторюваність результату, відсутність мутацій, заміну правил і розрахунки.
- `report/lab1.pdf` містить звіт про виконання лабораторної.

Для запуску потрібен Python 3.10 або новіший. З кореня репозиторію виконай `python3 Lab_01/main.py`.

Щоб запустити програму й усі перевірки, перейди до папки лабораторної.

```bash
cd Lab_01
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
python -m pytest
python -m mypy .
python -m black --check .
python -m ruff check .
```

У демонстрації звичайна квитанція становить 300,00 грн, пільгова — 135,00 грн. Разом — 435,00 грн.

# Лабораторна №8. Алгебраїчні типи даних у Python

Варіант 7. Результат операції.

- `model.py` описує незмінні вузли `Success[T]` зі значенням і `Failure` з повідомленням та кодом. `Result[T]` об’єднує ці два типи. `Literal` обмежує коди помилок, а протокол `Transform` описує функцію або об’єкт, який можна викликати з одним значенням.
- `evaluator.py` містить `divide`, `map_result` і `unwrap_or`. Ділення повертає помилку для нульового дільника або якщо результат завеликий для `float`. `map_result` застосовує перетворення до значення успішного результату. Для `Failure` він повертає той самий вузол. `unwrap_or` повертає вкладене значення або задане запасне.
- `pretty.py` формує текстове представлення обох вузлів через `match/case`. `main.py` демонструє обидва сценарії.

Варіант вузла визначає, чи була операція успішною. Наприклад, `Success(None)`, `Success(0)` і `Success(False)` є успішними результатами. Очікувані помилки обчислення представлені як `Failure`. Якщо передана функція перетворення сама підніме виняток, він пошириться до викликача.

Демо показує `Success(4.5)` для `9 / 2`. Після форматування це `Success('4.50')`. Для `9 / 0` демо показує `Failure[division_by_zero]` і запасне значення `недоступно`.

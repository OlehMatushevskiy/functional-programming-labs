# Лабораторна №4. Рекурсія та мемоізація

Варіант 7. Файлова ієрархія як дерево.

У `algorithms.py` файл містить ім’я й розмір у байтах. Каталог містить кортеж дочірніх файлів і каталогів. Дерево будується в пам’яті, тому приклад можна запускати з будь-якої папки.

- `directory_stats` повертає кількість файлів і сумарний розмір. База рекурсії: порожній каталог дає нулі. Крок: файл додає 1 до кількості та свій розмір до суми, а для підкаталогу додається результат такого самого рекурсивного підрахунку.
- `directory_dfs` використовує стек, а `directory_bfs` — чергу. Обидві функції починають із кореня й зберігають порядок дітей. `directory_stats_iter` підраховує файли за допомогою ітеративного DFS.
- `quicksort` розбиває послідовність на менші, рівні й більші за випадковий опорний елемент. Групу рівних повторно не сортує. Для 0 або 1 елемента одразу повертає новий список. Локальний генератор із фіксованим seed робить запуск відтворюваним.
- Для бінарного `Node` є рекурсивні генератори `preorder`, `inorder`, `postorder` та ітеративні `bfs_level_order`, `dfs_preorder_iter`. База рекурсії — відсутній вузол.
- `fib` кешує результати через `lru_cache`. База — індекси 0 і 1, крок — сума двох попередніх чисел. `fib_iter` обчислює ту саму послідовність циклом. Демонстрація показує `cache_info()` до очищення і розмір кешу після `cache_clear()`.

У CPython `sys.getrecursionlimit()` показує поточний ліміт рекурсії. Оптимізації хвостових викликів (TCO) немає, тому навіть хвостовий виклик додає кадр стеку. Для глибокого дерева безпечніше використати ітеративний DFS або BFS: їхній стек чи черга зберігаються в явній колекції. Ліміт у програмі не змінюється.

Для запуску потрібен Python 3.10 або новіший. З кореня репозиторію виконай `python3 Lab_04/main.py`.

```bash
cd Lab_04
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py --benchmark
python -m pytest -q
python -m mypy .
python -m black --check .
python -m ruff check .
```

Демонстрація дає 4 файли та 2960 байтів обома способами. `fib(25)` та `fib_iter(25)` повертають 75025. Після повторного виклику `fib(25)` кеш має 24 влучання й 26 промахів, після очищення — 0 записів.

Параметр `--benchmark` показує медіану трьох замірів по 10 000 підрахунків на тому самому дереві. В одному контрольному запуску рекурсивна версія зайняла близько 0,013 с, ітеративна — близько 0,011 с. Час залежить від дерева, машини та навантаження. Тести перевіряють результати, а не швидкість.

# Лабораторна №6. Замикання та декоратори як HOF

Варіант 7. Кешування результатів пошуку.

- `closures.py` містить `make_query_normalizer`, `make_logger` і `make_counter`. Нормалізатор зберігає налаштування регістру, логер — префікс, а лічильник змінює свій стан через `nonlocal`.
- `decorators.py` містить фабрики `timed`, `retries` і `cached`. Усі обгортки використовують `functools.wraps`, а сигнатури позначені через `ParamSpec` та `TypeVar`.
- `search.py` зберігає копію каталогу й нормалізує запит і категорію перед зверненням до кешу. Кеш стоїть зовні від таймера: повторний запит повертає збережений результат без нового виклику пошуку. Ключ розрізняє позиційні аргументи та іменовані аргументи, а порядок іменованих аргументів не впливає на збіг. Аргументи мають бути хешованими.
- `app.py` демонструє кеш, інвалідацію, сплив TTL та повтори. `main.py` запускає демонстрацію.
- `tests/` перевіряє метадані функцій, замикання, кеш, помилки та повтори. Час, логер, сон і джиттер можна підмінити через `Callable`. Тести не виконують реального сну чи мережевих запитів.

`timed` вимірює тривалість у секундах, мілісекундах або мікросекундах і логує її навіть за винятку. `retries` рахує початковий виклик як першу спробу, повторює лише вибрані винятки й не робить затримки після останньої спроби. Для проміжних спроб затримка дорівнює `delay * backoff ** (attempt - 1) + random_fn() * jitter`.

TTL відраховується після успішного обчислення. `ttl=None` означає запис без строку дії, `ttl=0` не дає повторно використати результат. `cache_clear()` очищає весь кеш, `cache_invalidate(predicate)` отримує `args` та `kwargs` запису й повертає кількість видалених записів. Для пошуку в `args` лежить нормалізований запит, а в `kwargs` — категорія й ліміт. Якщо під час обчислення кеш очистили або інвалідовували, старий виклик не заповнить його повторно.

Для запуску потрібен Python 3.10 або новіший. З кореня репозиторію виконай `python3 Lab_06/main.py`.

```bash
cd Lab_06
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
python -m pytest -q
python -m mypy .
python -m black --check .
python -m ruff check .
```

Запити `"  МИША "` та `"миша"` повертають `[1, 3]` після одного обчислення. Пошук з `limit=1` повертає `[1]` і кешується окремо. Предикат видаляє один такий запис. Для демонстрації спливу TTL годинник просувається на 30 секунд без очікування. Імітована операція з повторами завершується на третій спробі.

# Лабораторна №2. Аналіз товарів складу

Варіант 7. Мета — побудувати функціональний конвеєр з `map`, `filter`, композицією та окремою агрегацією через `reduce`.

- `core.py` додає до копії запису вартість запасу `total = price × stock`, застосовує коефіцієнт обраної категорії та відбирає товари зі `stock >= min_stock`. Далі конвеєр сортує за спаданням `total` і за зростанням `id` при рівності та бере перші `top_n` записів.
- `compose` застосовує функції справа наліво, `pipe` — у порядку передачі, а `juxt` застосовує всі функції до одного запису, наприклад для двох ключів сортування.
- `reduce_stats` повертає кількість записів, суму та середнє за їхньою вартістю. Для порожнього набору всі три значення нульові.
- `app.py` читає JSON і друкує Top-N та його статистику. `main.py` запускає функцію `main()` з `app.py`.
- `tests/test_core.py` перевіряє Top-N, композицію, агрегацію, незмінність даних і запуск програми.
- `sample_data.json` містить приклад даних, `ASSIGNMENT.md` — умову, а `pyproject.toml` — налаштування перевірок.

Для запуску потрібен Python 3.10 або новіший. З кореня репозиторію виконай `python3 Lab_02/main.py`.

Щоб запустити програму й усі перевірки, перейди до папки лабораторної.

```bash
cd Lab_02
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
python main.py --data sample_data.json --top 3
python -m pytest
python -m mypy .
python -m black --check .
python -m ruff check .
```

Без параметрів використовується `sample_data.json`, категорія «Електроніка», коефіцієнт 1,1, залишок від 1 та Top-2. Серед двох відібраних товарів `id` 1 та 2 сумарна вартість становить 462, середня — 231. Категорію можна змінити через `--boost-category`, коефіцієнт — через `--factor`, мінімальний залишок — через `--min-stock`. Параметр `--top 0` повертає порожній список.

# Лабораторна №3. Прокат автомобілів

Варіант 7. Мета — змоделювати прокат незмінними структурами, перевірити оновлення з поверненням нових об’єктів і порівняти час роботи зі змінною моделлю.

- `model.py` містить незмінні класи `Car`, `RentalOption`, `Rental` і `Invoice`. Опції оренди зберігаються в `tuple` у порядку додавання, характеристики авто — у `frozenset`. Строкові метадані копіюються в `MappingProxyType`.
- `core.py` додає опцію, продовжує оренду та змінює статус через `dataclasses.replace`. Підтримуються статуси `booked`, `active`, `completed` і `cancelled`. Додаткові вправи — `freeze` для вкладених словників, списків та множин і `apply_discount`, що повертає новий рахунок.
- `app.py` готує приклад оренди й друкує результат. `main.py` запускає цю демонстрацію.
- `tests/test_immutability.py` перевіряє нові копії, незмінність старих версій, хешованість і захист метаданих. Метадані враховуються під час порівняння оренд, але виключені з хешу, бо `MappingProxyType` над словником не хешується.
- `tests/test_performance.py` порівнює два однакові сценарії. У кожному з 50 000 повторів створюється оренда, додається GPS, подовжується термін і змінюється статус. Змінна модель оновлюється на місці. Незмінна створює нові версії. Тести перевіряють результат операцій, а час показує pytest.

Для запуску потрібен Python 3.10 або новіший. З кореня репозиторію виконай `python3 Lab_03/main.py`.

Щоб запустити програму й усі перевірки, перейди до папки лабораторної.

```bash
cd Lab_03
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
python -m pytest -q --durations=5
python -m mypy .
python -m black --check .
python -m ruff check .
```

Демонстрація додає GPS за 100 грн на день до авто за 1000 грн на день, продовжує оренду з 2 до 4 днів та змінює статус на `active`. Сума до знижки — 4400 грн, після знижки 10% — 3960 грн. Початкова версія лишається доступною в множині разом із новою.

У контрольному запуску змінна модель виконала сценарій приблизно за **0,01 с**, незмінна — за **0,29 с**. Ці числа залежать від машини та навантаження. Копії й перевірки під час створення нової версії додають накладні витрати, але попередні версії не змінюються, а метадані захищені від випадкового запису.

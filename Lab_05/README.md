# Лабораторна №5. Ліниві обчислення

Варіант 7. Сенсорні дані IoT. Мета — обробляти нескінченний потік вимірювань по одному значенню, не завантажуючи його повністю в пам’ять.

У `streams.py` генератор `sensor_stream` безкінечно повторює невеликий демонстраційний набір. Конвеєр `sensor_batches` робить три кроки:

1. `dropwhile` відкидає початкові значення нижче за `noise_threshold`. Значення на межі приймається. Після першого прийнятого вимірювання менші значення вже не відкидаються.
2. `takewhile` зупиняє обробку при значенні, що дорівнює або перевищує `emergency_threshold`. Це значення зчитується для перевірки порога, але не входить до результату. Далі дані не читаються.
3. `chunked` формує пакети по `batch_size` елементів. Самостійний `chunked` зберігає короткий останній пакет. Сенсорний конвеєр видає лише повні пакети.

Там само є `fib_stream`, нескінченний лічильник `naturals`, утиліти `take` та `drop`, ковзні вікна й середні, префіксні суми та добутки через `accumulate`. `take(n, it)` повертає список щонайбільше з `n` елементів, а `drop(n, it)` починає пропускати елементи під час першого запиту. Ковзні вікна й пакети використовують O(k) додаткової пам’яті для поточного буфера розміру k, якщо споживач сам не накопичує результати.

Порожнє джерело дає порожній результат. `take(0, it)` не читає джерело. Якщо вікно ширше за скінченний потік, повних вікон немає. Від’ємні `n` і непозитивні розміри вікна чи пакета відхиляються. Якщо нескінченне джерело ніколи не виходить зі стану початкового шуму, `dropwhile` не видасть першого вимірювання.

Для запуску потрібен Python 3.10 або новіший. З кореня репозиторію виконай `python3 Lab_05/main.py`.

```bash
cd Lab_05
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
python -m pytest -q
python -m mypy .
python -m black --check .
python -m ruff check .
```

У демонстрації початковий шум нижче 20, аварійний поріг 75, розмір пакета 3. Результат: `[(20.0, 22.0, 18.0), (24.0, 25.0, 26.0)]`. Значення 27 утворює неповний пакет, тому до результату не входить. Тести також перевіряють, що перший пакет отримується без прочитання наступного.
